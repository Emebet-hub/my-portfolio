# Cybersecurity & SIEM Analyst Portfolio

A responsive portfolio for Emebet Tegenaw Getahun, featuring cybersecurity experience, services, and fictional project demonstrations.

## Features

- Responsive layout with mobile navigation
- Dark and light themes with saved preference
- Project pages for SIEM analysis, network security, and a monitoring dashboard
- Downloadable CV
- Contact details with an email link

## Built with

- HTML
- CSS
- Vanilla JavaScript

No build step or package installation is required.

## Run locally

Open `index.html` in a browser. The site can also be served from any static web server.

## Publish with GitHub Pages

1. Push the repository to GitHub.
2. Open the repository's **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the branch containing the site (usually `main`) and the `/(root)` folder, then save.
5. Open the Pages URL shown in Settings → Pages after the deployment completes.

For a user site at `https://<username>.github.io`, the repository must be named `<username>.github.io`. Otherwise, GitHub Pages publishes a project site under `https://<username>.github.io/<repository>/`.

## Before publishing

- Confirm the photo, CV, email address, and social links are intended to be public.
- Replace `assets/documents/Emebet-cv.pdf` with the current CV if needed.
- The “Email me” button opens a Gmail compose window. Visitors need a Google account to send from Gmail; a contact form can be added later after connecting a form service.
- Project pages are demonstrations; their sample events and network data are fictional.
- No license file is included. Choose and add a license if you want to grant others permission to reuse the work.
